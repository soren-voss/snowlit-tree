# 雪夜礼物树 · Snowlit Tree

在雪夜里点亮一棵属于你的圣诞树，把礼物藏在树下，用一个链接送给 TA。

纯前端网页（Three.js + TypeScript + Vite），不需要服务器，可以直接部署到 GitHub Pages。

![点亮仪式](docs/ignite.gif)

## 功能

| 拆礼物 | 魔法形态 |
|---|---|
| ![拆礼物](docs/gift.gif) | ![魔法形态](docs/magic.gif) |

- **点亮仪式**：轻触后铃声响起，灯串从树底沿螺旋逐颗亮起，金珠链随之缠绕上升，最后树顶星星点燃。
- **拆礼物**：点礼盒后，镜头推近，蝴蝶结松开、盒盖翻落，光柱和金粉升起，最后弹出一张拍立得式卡片（照片、礼物名、祝福语、From / To）。拆过的礼盒保持打开，也可以"重新包装"。
- **自由欣赏**：可以拖动旋转、双指或滚轮缩放，闲置一会儿后会自动缓慢环绕。
- **魔法形态**：整棵树自下而上化作金色粒子，旋成一条星河；再点一次，粒子从上到下聚回成树。
- **许愿卡**：写下一句愿望，它会化作光点飞上树，挂成一枚小金卡，点一下就能看到内容。
- **彩蛋**：全部礼物拆完后，星星离开树顶绕树飞一圈，夜空下起流星雨，然后浮现总祝福语。
- **音乐音效**：用 WebAudio 实时合成的八音盒版《平安夜》《铃儿响叮当》《祝你圣诞快乐》，加上各种音效。项目里没有任何录音文件。
- **画质分档**：高 / 中 / 低三档，按设备自动选择，卡顿时自动降档。手机会加载缩小一半边长的贴图。

### 布置自己的树

![编辑面板](docs/editor.jpg)

点工具栏的"布置"打开编辑面板。电脑上它在右侧，手机上是底部抽屉；改动实时显示在场景里，并自动保存在这台设备的浏览器中（IndexedDB）。

- **礼物**：最多 12 个，可以增删、调整顺序（顺序就是树下从左到右的摆放顺序）。每个礼物可以设置：
  - 照片：6 张内置照片任选，或上传自己的照片（自动压缩成长边 1280px 的 WebP）。
  - 文字：礼物名、祝福语、From / To。
  - 礼盒：颜色、包装纹样（缎面 / 条纹 / 波点 / 金箔）、盒型（方盒 / 扁盒 / 高盒）。
- **场景**：
  - 收礼人和总祝福语。
  - 4 套主题配色：经典红金、冰蓝银、粉金、森林绿铜。
  - 雪量、背景音乐（也可以上传自己的音乐），以及管理树上的愿望。
- **分享**：
  - **分享链接 / 二维码**：内容压缩在网址 `#` 后面，不会上传到任何服务器。对方打开就能点亮、拆礼物；他看到的树是只读的，工具栏的"布置"会变成"我也做一棵"。
  - **礼物包（.json）**：包含上传的照片。对方打开网页后，在"布置 → 分享"里导入。也可以用来备份或换设备。

> 分享链接里**不包含你上传的照片**（链接放不下），对方看到的是没有照片的卡片。想带照片，请发礼物包。内置照片按编号放进链接，所以能正常显示。

### 录制模式（录短视频用）

在"布置 → 场景"里点"进入录制模式"，或者在网址后加 `?record=1`。

| 按键 | 作用 |
|---|---|
| `H` | 隐藏 / 显示所有界面 |
| `F` | 显示 9:16 竖屏取景框（只是参考线，不改变渲染尺寸） |
| `D` | 自动演示约 37 秒：点亮 → 环绕 → 拆两个礼物 → 魔法星河 → 复原 → 定格祝福语 |
| `Esc` | 退出录制模式 |

画面用系统录屏录下来即可。加上 `?seed=数字`，每次录到的雪花和灯光闪烁都一样。

## 快速开始

环境：Node.js 22 以上（已在 Node 24 上验证）、支持 WebGL 2 的浏览器。

```bash
npm install
npm run dev        # 开发服务器 http://localhost:5173
npm run build      # 类型检查 + 生产构建，输出到 dist/
npm run preview    # 本地预览构建结果
```

### 网址参数

| 参数 | 说明 |
|---|---|
| `?skipIntro=1` | 跳过点亮仪式，直接进入点亮后的状态 |
| `?quality=high` / `medium` / `low` | 固定画质档位，不再自动降档 |
| `?seed=1225` | 随机种子，影响树形细节、雪花和灯光节奏 |
| `?record=1` | 进入录制模式 |
| `#t=...` | 分享链接里的树数据（由"分享"页生成） |

开发模式下，`window.__tree` 暴露了场景状态和常用方法，方便调试和自动化测试。比如 `__tree.stats` 返回绘制调用次数，`__tree.openGift('cake')` 直接打开一个礼物。

## 部署到 GitHub Pages

仓库里已经带了 [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)：

1. 把代码推到 GitHub 仓库的 `main` 或 `master` 分支。
2. 在仓库的 **Settings → Pages** 里，把 **Source** 选为 **GitHub Actions**。
3. 之后每次推送都会自动构建并发布，地址是 `https://<用户名>.github.io/<仓库名>/`。

`vite.config.ts` 用的是相对路径 `base: './'`，部署在任意子路径下都能正常加载。

> 国内访问 GitHub Pages 可能较慢或不稳定，正式分享前建议先用手机 4G 网络实际打开试试。

## 二次创作指南

想改成自己的版本，可以从这些地方入手：

| 想改什么 | 在哪里改 |
|---|---|
| 打开网页时的示例礼物和祝福语 | `src/data/gifts.ts` 里的 `exampleScene` |
| 内置礼物照片 | 把图片放进 `public/assets/gifts/`（建议 3:2，约 1536×1024），然后在 `src/data/gifts.ts` 的 `PRESET_PHOTOS` 里登记 `id` 和名称 |
| 主题配色 | `src/scene/theme.ts`：每套主题定义了球饰、灯光、金珠链、星星和魔法粒子的颜色 |
| 背景音乐 | `src/audio/audio.ts` 的 `SONGS`：旋律写成 `音名八度:拍数`，比如 `G5:1.5`，`R` 表示休止；和弦写每小节的根音 |
| 树形与枝叶 | `src/scene/tree/shape.ts`（高度、半径、轮廓）和 `src/scene/tree/evergreen.ts`（枝条层数、密度、颜色） |
| 灯串数量与闪烁节奏 | `src/scene/tree/illumination.ts` |
| 各档画质参数 | `src/core/quality.ts` |
| 礼物数量和文字长度上限 | `src/data/gifts.ts` 的 `LIMITS` |
| 界面样式 | `src/ui/*.css` |

### 项目结构

```
src/
  main.ts        入口：搭场景、串起各模块、帧循环
  core/          渲染与后期、相机控制、画质分档、随机数、时间线
  data/          数据模型与校验、IndexedDB 存储、图片压缩、分享链接与礼物包
  scene/         夜空、雪地、飘雪、主题；tree/（树、灯、装饰、魔法形态、许愿卡）；gifts/（礼盒、开箱特效）
  sequences/     点亮、拆礼物、彩蛋的动画编排
  ui/            编辑面板、工具栏、礼物卡片、二维码
  audio/         八音盒音乐与音效合成
  textures/      贴图加载与程序生成的贴图
public/assets/   树木贴图和礼物照片（各目录有 SOURCES.md）
promo/           宣传片和 README 演示动图的逐帧渲染工具（见 promo/README.md）
```

## 浏览器与已知限制

- 需要 WebGL 2。桌面 Chrome / Edge / Safari / Firefox 的新版本都可以。
- **尚未在真机上测试**：中端安卓手机和微信内置浏览器里的流畅度还没验证。
- 背景音乐需要先有一次点击（比如"轻触点亮"）才能播放，这是浏览器的自动播放限制。
- 数据只存在当前浏览器里，清除浏览器数据会一起删掉。需要备份时请导出礼物包。
